XLRI BM 24–26 Digital Yearbook

GitHub Pages
1. Create a public GitHub repository.
2. Upload index.html, style.css, script.js, data.js and the images folder to the repository root.
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Wait a few minutes for the Pages deployment.

Important:
- Keep the images folder at the same level as index.html.
- The student order is alphabetical. Writer identities are intentionally not displayed.
- The Memory Wall includes a browser-only photo preview area for batch photos. Final batch photos can be added later to the repository images folder.
- All supplied images were resized for GitHub/browser performance.
